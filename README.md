# كيبورد ذكي AI — Android
## الخادم (إلزامي لأن مفتاح API لا يوضع في التطبيق)
cd server && ANTHROPIC_API_KEY=sk-... APP_TOKEN=سر-طويل node server.js
انشره على أي استضافة تدعم Node 18+ (Render / Railway / VPS) خلف HTTPS.
## التطبيق
افتح مجلد AiKeyboard في Android Studio ← Sync ← Run على هاتفك.
ثم من التطبيق: فعّل الكيبورد ← اخترْه ← ضع عنوان الخادم والـTOKEN ← احفظ.
ملاحظة: للإنتاج احذف usesCleartextTraffic من AndroidManifest واستخدم HTTPS فقط.
## الملصقات
- من تطبيق «كيبورد ذكي AI» اضغط «صانع الملصقات» أو من الكيبورد «🖼 ملصقات ← ＋ جديد».
- القص الذكي يستخدم ML Kit (يحتاج خدمات Google Play، وينزّل النموذج أول مرة).
- لخطوط عربية إضافية ضع ملفات .ttf في app/src/main/assets/fonts/ وستظهر في القائمة.
- الضغط المطوّل على ملصق في الكيبورد يحذفه. إن كان التطبيق لا يقبل الصور من الكيبورد تُفتح قائمة المشاركة.
