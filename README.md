# لوحة المفاتيح العربية — تطبيق Android

مشروع Android أصلي بلغة Kotlin يوفّر لوحة مفاتيح تعمل كـ Input Method (IME)، مع تخطيط عربي وإنجليزي وأدوات سريعة.

## التشغيل

1. افتح المشروع في Android Studio عبر **Open**.
2. ثبّت Android SDK 35 وJDK 17 عند الحاجة ثم نفّذ **Sync Project with Gradle Files**.
3. شغّل التطبيق على جهاز أو محاكي Android.
4. اضغط **تفعيل لوحة المفاتيح**، ثم فعّلها من إعدادات النظام.
5. ارجع واضغط **اختيار لوحة المفاتيح**.

## الميزات الحالية

- تخطيط عربي وإنجليزي وصف أرقام ورموز.
- تصحيح تلقائي محلي محدود، مع خيار إيقافه ويتخطى حقول كلمات المرور.
- زر حافظة يدرج النص الحالي عند الضغط عليه فقط؛ لا يحتفظ التطبيق بسجل للحافظة.
- اختصارات لفتح YouTube والويب.
- زر **🖼 ملصق** يفتح منتقي صور Android لاختيار صورة من الاستديو دون طلب صلاحية الوصول الشامل للصور. في التطبيقات التي تعلن دعم إدراج الصور عبر لوحة المفاتيح، يحاول إدراج الصورة مباشرة في المحادثة باستخدام واجهة Android القياسية. إذا لم يدعم التطبيق ذلك، تظهر قائمة مشاركة الصورة كبديل.
- اختيار الصورة يتم بفعل المستخدم فقط؛ لا يرفع التطبيق الصورة إلى خادم ولا يخزن سجلًا للصور.

## ملاحظة حول دعم الصور

إدراج الصور مباشرة يعتمد على التطبيق المستهدف؛ يجب أن يعلن التطبيق أنه يقبل أنواع الصور عبر IME. بعض التطبيقات أو حقول الكتابة لا تدعم ذلك، وقد يلزم استخدام مشاركة الصورة يدويًا. هذه الميزة ترسل الصورة كصورة/ملصق من الاستديو وليست حزمة ملصقات خاصة بتطبيق مراسلة.

## البناء

في Android Studio اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**. يظهر APK عادةً في `app/build/outputs/apk/`.

## الخصوصية والميزات المستقبلية

لا تطلب النسخة صلاحية الإنترنت. لا تُقرأ الحافظة إلا عند الضغط على زرها. الترجمة والذكاء الاصطناعي والنسخ الاحتياطي لم تُفعّل بعد؛ ينبغي تنفيذها بواجهات اختيار صريحة وإعدادات خصوصية مناسبة.
